Guía de Importación de Menú

Formato de archivo Excel (.xls / .xlsx) para importar productos y categorías al sistema

Campos del archivo

El archivo debe tener una fila por cada producto, con las siguientes columnas en la primera hoja:

ColumnaObligatorioValores aceptadosDescripción
CategoríaSíTextoNombre de la categoría (ej. "Entradas", "Hamburguesas"). Si no existe, se crea automáticamente.
NombreSíTextoNombre del producto (ej. "Birria Burger")
DescripciónNoTexto breveDescripción del plato que verán los clientes
Precio (COP)SíNúmero entero mayor a 0Precio en pesos colombianos
Imagen URLNoDirección web (URL)Enlace a la foto del producto. Si se deja vacío, se usa una imagen por defecto.
DisponibleNoSí / No (vacío = Sí)Si el producto está disponible para venderse
Si un producto ya existe por nombre (sin distinguir mayúsculas), se actualizan su precio, descripción, imagen y disponibilidad. Si no existe, se crea. Las categorías se crean automáticamente si no existen.

Preguntas frecuentes

¿Qué pasa con los productos que no están en el archivo? No se modifican. Mantienen su precio y datos actuales.

¿Qué pasa si una fila tiene errores? Las filas con errores se omiten y se muestran en el resumen. Las filas válidas se importan normalmente.

¿Puedo exportar el menú actual? Sí. En el diálogo de importar menú hay un botón "Exportar menú actual" que descarga un Excel con todos los productos existentes.
